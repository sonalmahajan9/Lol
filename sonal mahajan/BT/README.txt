BT PRACTICALS — QUICK GUIDE
==========================

ALL BT MATERIALS ARE .TXT FILES AS REQUESTED.
- Open the relevant .txt file in Notepad.
- For Solidity contracts, copy only the Solidity code into Remix in a file with a .sol extension.
- Website: https://remix.ethereum.org/
- Prefer Remix VM for practice and screenshots; no real funds are needed.

SECURITY
--------
Never share your Secret Recovery Phrase or private key. No legitimate support person needs it.
Test Ether on a test network has no real monetary value. Always verify the selected network and contract address.
