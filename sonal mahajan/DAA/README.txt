DAA PRACTICALS — RUN GUIDE
=========================

PYTHON
------
Open a terminal in DAA/Python and run a file like:
    python 01_fibonacci.py

JAVA
----
Open a terminal in DAA/Java. For each experiment, compile and run its file using its matching class name, for example:
    javac Fibonacci.java
    java Fibonacci

EXPERIMENTS
-----------
01 Fibonacci: recursive and iterative/non-recursive
02 Huffman encoding: greedy strategy
03 0/1 Knapsack: dynamic programming
04 N-Queens: backtracking (prints one solution)
05 Quick Sort: deterministic and randomized pivot

Inputs are requested by each program. Try small inputs first while revising.
